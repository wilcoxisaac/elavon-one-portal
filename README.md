# Elavon One Portal – concept prototype

A single, self-contained HTML prototype of a unified Elavon customer portal: one sign-in frame whose navigation and content change by experience.

- **Small Business** – Elavon POS: sales, online orders, tables, menu, inventory, customers, loyalty, team, deposits, reports, devices
- **Enterprise** – hierarchical regions › districts › locations, cross-location payments, settlement, interchange, disputes, fraud, APIs, reporting
- **Partner** – Reseller (portfolio, boarding, terminal jobs, residuals) and Developer (apps, Test Lab, API explorer, payouts)

Responsive from iPhone (including iPhone Duo) through iPad and large desktops.

**Live site:** https://wilcoxisaac.github.io/elavon-one-portal/

> Concept prototype with sample data only. Not a live Elavon service – no real accounts, payments or personal data are used. Brand assets © Elavon Inc. Elavon is a registered trademark in the United States and other countries.

Everything (styles, scripts, images) is inlined in `index.html`; open it in any browser, no build step or network needed.
